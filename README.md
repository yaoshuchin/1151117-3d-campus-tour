# 世新大學・漫遊校園 3D 互動導覽 (SHU Campus Tour 3D)

> 🏫 **在瀏覽器以第一人稱漫遊世新大學 3D 概念校園：從前校門穿過綠意隧道、舍我樓、大禮堂與操場，走到傳播大廈 C 棟。**

---

## 🌟 系統亮點與特色

- **第一人稱 3D 視角探索**：流暢穿梭前校門、綠意隧道、舍我樓、大禮堂、跑道操場至傳播大廈 C 棟。
- **免安裝即開即用**：基於 WebGL / Three.js 現代化前端架構，手機與電腦瀏覽器皆可順暢漫遊。
- **身歷其境影音體驗**：內建高畫質校園漫遊影音串流與專屬環境背景主題配樂（`tour-theme`）。
- **通行門禁安全防護**：搭載磨砂玻璃門禁驗證機制（Password Gate），提供研習、參訪與專案成果展示保護。
- **本機驗證狀態快取**：通過金鑰驗證後狀態儲存於瀏覽器本機，重新整理或換頁無需反覆輸入。
- **一鍵快速鎖定**：畫面常駐浮動「🔒 鎖定網站」快捷按鈕，隨時可一鍵返回門禁鎖定模式。

## 🧭 漫遊控制方式

| 操作 | 電腦版鍵盤與滑鼠 | 行動裝置觸控 |
| :--- | :--- | :--- |
| **移動視角** | `W` / `A` / `S` / `D` 或 方向鍵 | 螢幕虛擬搖桿 |
| **環顧四周** | 滑鼠拖曳視角 | 單指滑動螢幕 |
| **全螢幕切換** | 點擊右上方全螢幕圖示 | 點擊右上方全螢幕圖示 |
| **音樂開關** | 點擊音樂喇叭圖示切換播放/靜音 | 點擊音樂喇叭圖示切換播放/靜音 |
| **安全鎖定** | 點擊右下角「🔒 鎖定網站」 | 點擊右下角「🔒 鎖定網站」 |

---

## 🛡️ 安全性與存取防護說明

- **通行身分驗證**：進入系統前需輸入專屬通行金鑰（Passcode），驗證通過後方可解鎖 3D 場景。
- **安全比對機制**：支援 SHA-256 單向雜湊即時比對，兼顧相容性與資安防護。
- **狀態儲存機制**：金鑰存取權限由瀏覽器端儲存，保障展示流程流暢不斷線。

## 💻 快速本地預覽

1. 雙擊執行 `start_local.bat`。
2. 或在終端機執行：
   ```bash
   python -m http.server 8099
   ```
3. 開啟瀏覽器造訪：`http://localhost:8099/`
